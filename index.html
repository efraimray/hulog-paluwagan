About this project

A paluwagan without the notebook and the arguments

The problem

A paluwagan (rotating savings group) usually lives in one person's notebook and a group chat. Members lose track of whose turn it is, who has not paid their hulog yet, and whether the payout order was drawn fairly.

Who it is for

Office barkadas, market vendors, cooperatives, church and school groups, and the organizer who collects every kinsenas and katapusan.

What it does

  • Payout calendar for weekly, every 2 weeks, 15th & end of month, or monthly
  • Members can hold more than one ulo (slot)
  • Fair bunutan: a seeded draw anyone can re-check
  • Tap-to-mark hulog tracker with late and collecting states
  • Optional organizer fee, Sunday-to-Monday payout rule
  • Messenger-ready summary, CSV export, JSON backup

How it is built

HTML, CSS and vanilla JavaScript. No framework, no server, no sign-up. Data stays in this browser's storage. The logic lives in one pure file with 12 automated tests.

Install

Open index.html, or host the folder on GitHub Pages or any web host. It also works offline as an installable web app.
